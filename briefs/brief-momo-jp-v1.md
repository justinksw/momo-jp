## 1. 情報設計

```

  ├─ ヘッダー（サイト名のみ・短い）
  ├─ 期間フィルタ（単一選択）
  ├─ カテゴリフィルタ（複数選択）
```

## 2. Hub レイアウト

### 2.1 ヘッダー

- タイトル案: **勉強メモ** または **momo-jp**（どちらか短く。推奨 **勉強メモ**、小さく `momo-jp` を副標）
- サブコピーなし（「Explore…」系禁止）

### 2.2 期間フィルタ（単一）

横スクロール可のチップ行。**必ず 1 つ選択**（初期: **今日**）。

| value | ラベル |
|-------|--------|
| day | 今日 |
| week | 今週 |
| month | 今月 |
| year | 今年 |
| all | 全部 |

定義（フィルタ計算・Jessie）:

- **今日** — `date ===` 端末ローカル当日（Asia/Hong_Kong）
- **今週** — 月曜始まり〜日曜（HK）の範囲に `date` が入る
- **今月** — 同年同月
- **今年** — 同年
- **全部** — 期間制限なし

カテゴリとの関係: **AND**（期間 ∩ 選んだカテゴリ全部を含むカード）。カテゴリ未選択＝カテゴリ制限なし。

### 2.3 カテゴリフィルタ（複数）

チップ。トグルでオン／オフ。スラッグは plan 固定。表示ラベル:

| slug | ラベル |
|------|--------|
| vocabulary | 語彙 |
| grammar | 文法 |
| fun-fact | 豆知識 |
| history | 歴史 |
| society | 社会 |
| culture | 文化 |
| food | 食 |
| living | 生活 |
| travel | 旅行 |
| fashion | ファッション |

hub では **サンプルに出ている＋今後増えうる全スラッグ**を出せる構造に（チップはデータに存在するカテゴリだけでも可。推奨: plan の全スラッグを常時表示し、0 件のときだけ薄く）。

補助: 「カテゴリで絞る」はセクション見出しにしてよい。クリアは **カテゴリを全部オフ**で足りる（専用「クリア」ボタンは任意・短く「解除」）。

### 2.4 一覧行（1 カード）

1 行タップ領域。最低限:

- **title**（主）
- **date**（例: `11月5日` または `2026-11-05` — 推奨 `11/5`＋年は今年以外だけ表示）
- **categories** — 小さチップ 1〜n

余白タップターゲット ≥ 44px 高。区切りは薄い線またはカード型（紙ノートならフラット行＋下線で十分）。

### 2.5 空状態

短く: **「この条件のカードはないよ」**  
フィルタを変える以外の CTA なし。

### 2.6 件数（任意だが推奨）

フィルタ下に `3件` のように小さく。

## 3. カード詳細レイアウト

- 先頭: **戻る**（hub へ）。ブラウザ戻ると同じでも、明示リンク必須。
- タイトル: `title`（ページ H1）
- メタ行: 日付（読みやすい日本語）＋カテゴリチップ（hub と同じラベル表）
- 本文: MD → HTML。読み順を壊さない。
  - 日の例文は少し目立たせる（引用ブロックまたは大きめ本文）
  - `**語**` は太字のまま
  - 中文は日文と混在してよい（Momo どおり）。強制二カラムにしない
- 前後カードナビは v1 任意（無しでよい）

タイポ（目安）:

- 本文 17–18px、行間 1.55–1.7（中日混在で窮屈にしない）
- 最大幅 ~40rem、左右 padding ≥ 16px（320px 幅でも）

## 4. UI 文言（ロック）

使ってよい: 今日・今週・今月・今年・全部・語彙・文法・豆知識・歴史・社会・文化・食・生活・旅行・ファッション・戻る・勉強メモ・カテゴリで絞る・解除・件・この条件のカードはないよ  

禁止: 英語スローガン、Unlock / Explore / Dive、AIが厳選、スマート学習、パーソナライズ系。

---

## 5. ビジュアル（Direction A · 紙ノート）

- 背景: オフ白 `#F7F4EF` 前後
- 文字: ほぼ黒 `#1A1A1A`、二次 `#5C5C5C`
- チップ選択中: 濃いめ塗り＋白字、または枠＋薄い塗り（コントラスト AA 以上）
- カテゴリ色: 全色分けしすぎない。**同一スタイルのニュートラルチップ**でラベルだけ変える（色覚・シンプル優先）。必要なら vocabulary／grammar だけごく薄い色差。
- フォント: システム日本語優先（`"Hiragino Sans", "Noto Sans JP", system-ui`）
- 装飾: ヒーロー画像・マスコット大写しなし。favicon 程度は可。

---

## 6. レスポンシブ

- モバイルファースト。設計基準幅 **390px**。
- 必須証明幅: **320 / 360 / 390 / 430**
- デスクトップ: 一覧は中央カラム max ~560–640px（ノート幅）。ワイドで無理に多カラムにしない（v1）
- **desktop Chrome** と **iPhone WebKit**（Safari ＋ iOS Chrome）で横スクロール無し・チップがはみ出して本文を消さないこと

## 7. Acceptance list（矛盾なし・計測可）

1. hub で期間（今日／今週／今月／今年／全部）単一選択が動く。初期は今日。
2. hub でカテゴリ複数トグルが動く。未選択＝カテゴリ制限なし。期間と AND。
3. 一覧にサンプル 3 枚が条件に応じて出る／隠れる。`全部`＋カテゴリなしで 3 件。
4. 一覧行に title・日付・カテゴリチップ。タップで詳細へ。
5. 詳細に戻る・title・日付・カテゴリ・MD 本文（例文→語彙／変化→中の説明の順が読める）。
6. UI 文言が §4 の日本語のみ。英語スローガン無し。
7. 320–430px で横スクロール無し。本文折り返し可。タップ高 ≥ 44px（フィルタチップ・戻る・一覧行）。
8. desktop Chrome と iPhone WebKit（Safari・iOS Chrome）で 7 を満たす。
9. テキストコントラスト: 本文・ラベルが背景に対しおおむね 4.5:1 以上。
10. PREVIEW 時は PREVIEW バッジ（Jessie／`pages-preview-live`）。LIVE は Justin OK 後のみ。
11. 教材 MD の文言をデザイン側で書き換えない（表示のみ）。
12. 静的 GitHub Pages。ログイン無し。
